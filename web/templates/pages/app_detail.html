Storage

Backup dump command

{{/* The note belongs to the row above it, so the two are one item of the stack rather than two spaced apart. */}}

Run in the container before each backup; its output is archived as dump.sql. Set this for anything holding a database: copying a running database's files gives an archive that may not reload. The command runs with the container's own environment, so reference $POSTGRES_USER and friends instead of hardcoding credentials. A failing command fails the backup. Empty means the data directory is copied as-is.

Custom domains

Redeploy to apply. Point DNS at this server first.

Deploy webhook

POST to this URL (e.g. from a GitHub push webhook) to trigger a redeploy:

https://admin.{{.Domain}}/hooks/{{.ID}}/{{.WebhookSecret}}

Keep this URL secret — anyone who has it can redeploy the app.

Health check

HTTP path probed every 30s; 3 failures restart the container. Empty disables.
