How a repository is matched

A clone URL resolves to exactly one credential: the narrowest scope that covers it. Given these three,

github.com/acmework token
github.compersonal token
{{.AnyScope}}catch-all
github.com/acme/api.git→ work token
github.com/me/blog.git→ personal token
gitlab.com/x/y.git→ catch-all

Scopes only ever break on a /, so github.com/acme never claims github.com/acmecorp. A scope with no port still covers a forge served on one, but a scope that names a port only matches that port. URLs that are not https://, and URLs that already carry credentials of their own, are left exactly as they are — an SSH deploy key keeps working and is never touched by anything on this page.
