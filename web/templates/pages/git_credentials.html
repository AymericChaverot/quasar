How a repository is matched

A clone URL resolves to at most one credential, in this order:

  1. host:port exactly as it appears in the URL
  2. host without the port
  3. {{.AnyHost}}, the fallback

The first match wins, so a credential for a specific host is never overruled by the fallback. URLs that are not https://, and URLs that already carry credentials of their own, are left exactly as they are — an SSH deploy key keeps working and is never touched by anything on this page.
