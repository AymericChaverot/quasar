For driving Quasar from a pipeline. Send it as Authorization: Bearer <token>. Only the hash is stored, so a copy of the database does not yield working credentials — and a lost token cannot be recovered, only revoked and replaced.

A viewer token can list and inspect applications and read host metrics; an admin token can also deploy and restart. No token can read an application's environment variables or compose file: a credential sitting in CI configuration is a weaker place than the encrypted column those values live in.

Notifies once when the server crosses a threshold, and again when it recovers. A full disk is the most common way a VPS goes down, so disk warns earliest. Set one to 0 to turn it off.
